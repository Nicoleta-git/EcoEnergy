# Stage 9. Digital mockup

**Done by:** Nicoleta and Faina (we worked at the same time)

**Mockup in Figma:** [EcoEnergie](https://www.figma.com/design/Bkr6FzsNb0wzooRl5pZgqT/EcoEnergie)

## How we made it

1. We started from the wireframe and the paper sketches.
2. We drew every screen in Figma, on the page "Macheta", with the colors and font below. We made the side menu once, as a component, and put it on every screen.
3. We linked the screens in Prototype mode (see [10_navigation.md](10_navigation.md)).

## The screens

| No. | Screen | What it shows |
| --- | --- | --- |
| 1 | Start | The logo on a photo of the college, the loading bar |
| 2 | Login | The login form; the version with an error message |
| 3 | Dashboard | Today's usage, the list of rooms, the 3D building, the 14-day chart; the assistant panel |
| 4 | Room page | The data of one room, its devices, the QR code |
| 5 | QR code on a phone | The phone-shaped window with the QR code |
| 6 | Live monitoring | The gauge, the sensor values, the Arduino board, the 60 s chart |
| 7 | Meter readings | The form; the versions with an error and with a confirmation |
| 8 | Bills | The bill form and the saved bills |
| 9 | Reports and charts | The charts, the ranking, the statistics |
| 10 | STEM calculators | The physics and math formulas |
| 11 | Eco tips | The tips with calculations and the college goal |
| 12 | Design the classroom | The devices, the classroom, the cost, the notes |
| 13 | Settings | The limits, the tariff, the data source, the theme |
