**1. What was the hardest design decision and why?**

Removing the alerts page. It was in the material, but the screen repeated what the colors already showed: a red room already means "over the limit". We kept the green / yellow / red colors everywhere and dropped one extra screen.

**3. Which STEAM component was the hardest and how did you handle it?**

Engineering: connecting the INA219 sensor to the Arduino and getting the data into the app once per second. We first made a simulator that gives similar values, so we could work on the screens without the board.

**4. What would be the first three features to build in code?**

1. Saving the readings in a database.
2. Connecting an Arduino board in every room.
3. Reading the bill automatically from a photo.

**5. What would you do differently?**

We would start with the paper wireframe before the colors and test the mockup with classmates earlier.
